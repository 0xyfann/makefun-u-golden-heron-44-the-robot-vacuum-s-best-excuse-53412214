One funny one-line excuse from a robot vacuum for missing a spot, for the make.fun competition "The Robot Vacuum's Best Excuse".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> I mapped that dust bunny as a new roommate, so legally I can't vacuum him without a 30-day eviction notice.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
